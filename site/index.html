Lint an MCP config without running it

Paste an MCP config (.mcp.json, Claude Desktop, Cursor, VS Code) and mcp-frisk flags command and args shaped like shell injection or carrying inline code, API keys sitting in plain text, and settings that start a repo's servers without asking. It runs the same rule code as the mcpfrisk CLI, here in your browser: nothing you paste is sent anywhere, and no server is started.

Findings show up here as you paste. The sample's keys are planted fakes.
